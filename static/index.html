B

BERO 账户

尚未连接

使用 BERO 官方邮箱和密码登录流程，勾选商家的「保持登录」。密码与 Cookie 会话加密保存在这台 VPS 上；重启后优先复用会话，保存的密码不会返回网页。支持邮箱密码登录；第三方登录和二步验证尚未适配。

验证只登录并检查会话，不创建订单或扣款。购买执行仍关闭，账户验证通过后还需核实真实结账流程。

NOTIFICATIONS

通知设置

Bark、微信（PushPlus / Server酱 / 企业微信）与 Telegram 可单独使用，也可同时接收提醒。

B

Bark 强提醒

尚未连接

官方服务器地址已填好。在 Bark App 中复制设备 Key，填写到下方独立栏目。自建服务请填写公网 HTTPS 域名，使用443端口。保存后 Key 不会显示。

强提醒应用于补货和测试消息；监控异常使用普通通知。音量只在「重要警告」下生效，请在 iPhone 设置里允许 Bark 通知及「重要警告」，并用测试确认实际响铃。

设备 Key 加密保存在 VPS 上，保存后不会返回前端。每轮补货按渠道去重；发送失败只重试失败渠道。启用新渠道不会重发已完成的补货提醒。

测试使用已保存设置，点击后手机可能持续响铃 30 秒。显示发送成功表示 Bark 服务端已接收，实际送达以手机为准。

TASK CONFIGURATION

添加监控任务

页面价格上限用于判断标价是否可接受。BERO 任务的优惠码会在结账时填入并核对；其他商家只做记录。

BERO 套餐页上每张套餐卡片都有编号（页面里的 selectPackage(编号)）。名称、规格和周期必须与页面文字完全一致，任何一项对不上程序都会停止，不会下单。
大多数 VPS 小商家使用 WHMCS。在商家网站点「立即订购 / Order Now」，把跳转前的链接（形如 …/cart.php?a=add&pid=123）粘贴到上面的「商品页面」，或填写 WHMCS 首页地址再在下面填商品编号。程序按 WHMCS 自带的缺货判断检查，不需要登录；价格上限可以留空。
页面用 JavaScript 加载、下载不到库存文字时使用。在浏览器 F12 → Network → Fetch/XHR 里找到商品的接口地址，填到上面的「商品页面」；再填下面几项，告诉程序在返回的数据里怎么找到这个商品。库存字段大于 0 视为有货。
适用于无需登录、HTML 中直接含价格和库存的商品页。动态页面需要单独适配。

缺货文字优先。价格不支持千分位分隔；匹配不明确时只记录异常，不报有货。

网站按 IP 拦截（HTTP 403）时，可填自己的出口代理，只对这个任务生效。代理地址不会写入导出文件。

保存后保持暂停，可先单次检查。
